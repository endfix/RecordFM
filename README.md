# RecordFM

Небольшой десктопный плеер для прослушивания станций Radio Record. Приложение показывает текущий трек, позволяет выбрать качество потока, управлять громкостью и настраивать эквалайзер.

Требуются Windows и .NET 6 SDK.

```powershell
dotnet run --project Record.csproj
```
